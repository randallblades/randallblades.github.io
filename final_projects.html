NASA Meteorite Tracking Database

A Java application designed to parse, filter, and analyze NASA meteorite landing data. This project demonstrates intermediate object-oriented design patterns, JSON data handling, and an interactive user interface.

Project Walkthrough

Project Screenshots

Features

  • JSON Data Parsing:
    Dynamically reads and loads complex geographic and historical meteorite records from an external data source using Gson.
  • Interactive User Interface:
    A custom terminal-based user interface (UserInterface.java) that allows users to navigate, filter, and search through database records efficiently.
  • Geolocation & Data Modeling:
    Features robust class structures like Meteorite.java and Geolocation.java to handle coordinate and tracking logic cleanly.

Technologies Used

  • Language:
    Java
  • Library:
    Google Gson Library for JSON Parsing
  • Concepts:
    Object-Oriented Programming, File I/O, Data Modeling, Encapsulation, Text-based UI Design

How to Run the Project

  1. Clone or download the project repository from GitHub.
  2. Ensure you have Java Development Kit (JDK) installed on your machine.
  3. Compile the Java files using a terminal or command prompt.
  4. Run the main class (e.g., Main.java) to start the application.
  5. Follow the on-screen prompts to explore meteorite data.
